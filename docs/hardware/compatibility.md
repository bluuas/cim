# Compatibility

Which boards a firmware release supports. The PR that changes the support updates this page and the supported-boards line of the release notes ([BRD-02](../conventions.md#brd-02-every-release-states-the-boards-it-supports-must)).

| Board | `PICO_BOARD` | MCU | Flash | Firmware |
|---|---|---|---|---|
| CIM prototype v7 | `cim_proto_v7` | RP2040 | W25Q16JV, 2 MB external | all releases |

The next-generation board CIM v0 is tracked in [#74](https://github.com/bluuas/cim/issues/74) and is not supported yet.
